# 🎮 Tic-Tac-Toe Game

## 📌 About the Project
This is a simple and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

I built this project as part of my JavaScript learning journey to practice frontend development, DOM manipulation, event handling, and game logic.

The game allows two players to play against each other and displays the winner when a player successfully completes a winning combination.

## 🛠️ Technologies Used
- **HTML** – To structure the game interface.
- **CSS** – To style the game board and create a user-friendly layout.
- **JavaScript** – To implement game logic, player interactions, and winning conditions.

## ✨ Features
- Interactive 3 × 3 game board.
- Two-player gameplay.
- Automatic winner detection.
- Draw detection.
- New Game functionality.
- Responsive and simple user interface.

## 🎯 What I Learned
Through this project, I practiced:

- DOM manipulation using JavaScript.
- Event listeners and click events.
- Conditional statements and arrays.
- Implementing game logic.
- Checking winning combinations.
- Connecting HTML, CSS, and JavaScript.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/SrimukhiMuniganti/Tic-Tac-Toe-game.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start playing the game!
